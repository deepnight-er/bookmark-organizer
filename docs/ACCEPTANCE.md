# 兼容与验证

以下为 1.0.0 的验证范围，记录日期为 2026-11-13。发行状态与发布日期以仓库 Releases 和更新记录为准。

## 支持环境

- Chrome 134+。
- 网页预览用于体验示例书签，Chrome 扩展用于管理浏览器书签。
- 界面提供 12 种语言，阿拉伯语使用从右向左布局。

## 已验证范围

| 环境 | 覆盖内容 | 结果 |
|---|---|---|
| 自动测试 | 外部修改保护、撤销重试与重开恢复、分类管理、导入取消及继续、发布记录一致性 | 119 项通过 |
| 网页预览 | 20,000 条导入、取消、继续合入、分批显示、搜索及整批撤销 | 通过 |
| 界面布局 | 1440、623、390 像素窗口，多语言、深色主题及阿拉伯语布局 | 已测窗口无横向溢出 |
| Chrome 扩展 | 安装、原路径重载、80 条及 500 条导入、取消与继续、整批撤销 | 通过 |
| 网页标题读取 | example.com 站点授权拒绝与允许、编辑草稿保留、标题保存 | 通过 |
| Chrome 多窗口 | 书签更新、操作记录读取、跨窗口撤销 | 通过 |
| 同一账号的两个 Chrome 资料 | 新增、反向修改网址、改名、移动至二级分类、删除、撤销及刷新恢复 | 本机往返通过 |
| 构建产物 | 32 个运行文件与本地目录逐字节对比、ZIP 清单及内容校验、重复构建 | 通过 |

账号同步验证完成后，测试书签及两个临时 Chrome 资料已清理。认证信息和已登录界面截图由维护者在本机管理。

Linux 与 Windows 的自动检查由 GitHub Actions 执行，每次提交的结果可在仓库中查看。[查看自动检查](https://github.com/deepnight-er/bookmark-organizer/actions)

## 复现自动检查

```sh
npm test
npm run check
npm run build
npm run check:release
```

安装与书签写入测试应使用独立 Chrome 资料和自行构造的测试书签。网页预览通过后，还需在 Chrome 中核对权限、写入、撤销和重新打开的结果。
