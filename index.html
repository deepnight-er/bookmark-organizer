如何使用

当前展示公开示例，可直接练习整理，操作保存在本机。

打开自己的 Chrome 书签

点击 Chrome 工具栏的扩展图标，再点击“书签整理”。扩展会自动显示当前 Chrome 个人资料的书签，编辑、移动和删除会直接保存，账号同步沿用 Chrome 的设置。

更新过本地代码时，先在扩展管理页点一次重新加载。

首次安装扩展

安装后会自动打开书签页面，并读取当前 Chrome 书签。

下载扩展包
  1. 解压下载的扩展包。
  2. 在 Chrome 地址栏打开 chrome://extensions，开启开发者模式。
  3. 点击“加载已解压的扩展程序”，选择包内的 extension 文件夹。

扩展申请书签和本机存储权限。安装操作由 Chrome 管理。

整理书签

查找
选择一级分类，在列表上方筛选二级分类，或按名称、网址搜索。
编辑
点击书签右侧的铅笔，在原行修改名称、前缀和网址。
移动
拖到右侧分类。悬停一级分类可展开二级，也可勾选多条后批量移动。
管理
在“分类管理”中改名、新建和调整目录，也可查找重复或导入备份。页头可撤销、查看操作记录、刷新及导出。

操作记录

记录仅存于本机。展开查看明细，或撤销其中一次操作。

保留最近 200 条记录，最近 30 次操作可撤销。一次撤销会恢复该条记录中的全部更改。
